    Complete FastAPI + PostgreSQL + Telegram Bot + Google Photos OAuth + Docker/Nginx deployment

    1. Zero-Loss Telegram Storage

    Uses sendDocument with application/octet-stream so Telegram never strips EXIF tags or recompresses JPEGs/PNGs/RAWs.

    2. Non-Destructive Lossless Sidecar

    Generates a separate lossless WebP/PNG/JPEG Huffman-optimized companion while keeping the exact original file untouched.

    3. PostgreSQL + TG Snapshot

    Stores folder trees, SHA-256 hashes, EXIF fields, and Telegram file_id pointers in PostgreSQL with 1-click pg_dump backup to your Telegram chat.
